# Roadmap

O projeto vai crescer em etapas pequenas para que cada resultado possa ser conferido antes de incluir automações mais complexas.

## Etapa 1 — Base do projeto

- [x] Documentar o problema e o MVP
- [x] Criar estrutura Python instalável
- [x] Ler PDFs locais e exportar texto para CSV
- [ ] Reunir um pequeno conjunto de editais públicos de exemplo
- [ ] Conferir manualmente a extração em diferentes formatos de PDF

## Etapa 2 — Pesquisa e organização

- [ ] Permitir busca por palavras e expressões nos textos
- [ ] Extrair campos simples, como órgão, objeto, modalidade e datas, com indicação da evidência
- [ ] Registrar erros e documentos sem texto extraível de forma clara

## Etapa 3 — Interface e documentos digitalizados

- [ ] Criar uma interface simples para carregar e filtrar editais
- [ ] Avaliar OCR para PDFs que são imagens
- [ ] Mostrar trechos de origem para cada informação apresentada

## Etapa 4 — Recursos de IA

- [ ] Definir tarefas específicas para IA, como resumo e organização de requisitos
- [ ] Comparar as respostas com uma amostra revisada manualmente
- [ ] Exibir incertezas e links/trechos do edital junto das respostas
- [ ] Manter revisão humana e não tratar a saída como parecer jurídico ou decisão automática

## Critério para avançar

Antes de adicionar uma nova etapa, verificar a anterior com documentos reais e registrar limitações conhecidas. Informações importantes devem poder ser conferidas no documento original.
